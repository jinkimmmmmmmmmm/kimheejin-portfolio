# 내 페이지 템플릿

「내 페이지 만들기」 수업 재료입니다. JavaScript 없이 HTML과 CSS만으로 만들어서, 받아서 더블클릭하면 바로 열립니다.
**글자만 내 이야기로 바꾸면** 내 소개 페이지가 됩니다.

## 1. 열어 보기
1. 받은 ZIP 파일을 오른쪽 클릭 → **모두 압축 풀기** (압축을 풀지 않고 열면 모양이 나오지 않습니다)
2. 풀린 폴더의 `index.html` 을 더블클릭하면 예시 페이지가 열립니다
3. 영상 자리에 「오류 153」이 보이는 것은 정상입니다. 인터넷에 올리면 영상이 나옵니다

## 2. 내 이야기로 바꾸기
Antigravity 에서 **Open Folder** 로 `index.html` 이 바로 보이는 폴더를 열고, 채팅창에 아래 문장을 붙여 넣으세요. 괄호 부분만 내 것으로 바꿉니다.

- `index.html 의 글자만 내 이야기로 바꿔 줘. 새 파일은 만들지 말고, 태그와 class, style.css 는 그대로 둬. DESIGN.md 를 지켜. 내 이야기는 이래: (여기에 내 이야기)`
- `첫 화면 버튼과 연락처의 카카오톡 오픈채팅 주소를 이 주소로 바꿔 줘. 다른 곳은 바꾸지 마: (내 오픈채팅 링크)`
- `images 폴더에 내 사진 my-photo.jpg 를 넣었어. index.html 의 사진 주석 설명대로 첫 화면 사진 자리에 연결해 줘. 다른 곳은 바꾸지 마.`
- `style.css 맨 위 한 줄의 대표색만 (원하는 색)으로 바꿔 줘.`
- `경력 칸을 하나 더 만들어 줘. 위 칸 모양을 그대로 복사하고, DESIGN.md 를 지켜.`

직접 고칠 때는 `index.html` 안의 안내(「경력 시작」「경력 끝」 등)를 보세요. 안 쓰는 부분은 그 사이를 통째로 지우면 됩니다.

## 3. 알아 두면 좋은 것
| 파일 | 하는 일 |
|---|---|
| `index.html` | 글과 구조. 여기 글자만 바꿉니다 |
| `style.css` | 디자인. 맨 위 한 줄이 대표색 |
| `DESIGN.md` | 이 디자인의 규칙. AI 에게 「DESIGN.md 를 지켜」라고 하면 같은 모양으로 늘려 줍니다 |
| `images/` | 그림. `og.jpg` 는 카톡으로 주소를 보낼 때 뜨는 그림(가로 1200 × 세로 630) |

- **카카오톡 오픈채팅 주소**: 오픈채팅방 → 공유 → 링크 복사
- **사진**: 파일 이름은 영어 소문자로 짧게(`my-photo.jpg`). 아이폰 사진(`.heic`)은 크롬에서 보이지 않으니 JPG 로 바꿔 넣으세요
- **카톡 미리보기 그림**: 인터넷 주소가 생기면 `index.html` 위쪽 `og:image` 를 `https://내주소/images/og.jpg` 처럼 전체 주소로 바꾸세요
- **다른 디자인으로 바꾸기**: 다른 템플릿의 `style.css` 와 `DESIGN.md` 를 가져와 덮어쓰면 글은 그대로 두고 디자인만 바뀝니다(작업물 그림은 따로)

## 5. 막힐 때
| 이런 일이 생기면 | 이렇게 |
|---|---|
| 모양과 그림이 안 나와요 | 압축을 풀었는지 확인 |
| 버튼을 눌러도 카카오톡이 안 열려요 | 「내오픈채팅주소」 자리를 내 링크로 바꾸기 |
| 사진이 안 떠요 | 파일 이름과 확장명(.jpg / .png) 확인, 아이폰 사진은 JPG 로 |
| AI 가 파일을 잔뜩 만들었어요 | 「방금 바꾼 거 되돌려 줘」, 안 되면 ZIP 을 다시 받아 처음부터 |
